# omnishow/youtube

YouTube for `glitchr/omnishow`, the family for video sources hosted elsewhere: a channel's and a playlist's videos, a player a page can drive.

> **Reserved, not released yet.** This repository holds the package's name. It contains no code and
> has no tagged version: do not install it. The package will be written here.
